# CloudQuiz

Quiz de révision du cours **Cloud Infrastructures** (ING3 ICC, CY Tech), déployé automatiquement sur **Google Cloud Run** par un pipeline **Cloud Build** à chaque push sur `main`.

- Application : Node.js 22, Express, HTML/CSS/JavaScript, Bootstrap 5
- Lancer en local : voir [docs/installation.md](docs/installation.md)

> README complété par l'équipe : architecture, pipeline, rollback, captures.
